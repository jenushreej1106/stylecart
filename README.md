# 🛍️ StyleCart – Online Shopping Cart

StyleCart is a web-based online shopping cart application developed using Laravel, PHP, MySQL, HTML, CSS, and JavaScript. It allows users to browse products, manage their shopping cart, maintain a wishlist, and place orders.

## ✨ Features

* **Product Management** – Add, edit, delete, and view products.
* **Category Management** – Organize products by category.
* **Product Search** – Search and filter products.
* **Shopping Cart** – Add products, update quantities, and remove items.
* **Wishlist** – Add and remove favorite products.
* **Checkout** – Enter customer details and place orders.
* **Order Management** – View orders and update order status.
* **Dashboard** – View product, category, order, and sales statistics.
* **Product Images** – Upload and display product images.
* **Responsive UI** – Stylish black-and-gold design.

## ⚙️ Installation

### 1. Clone the Repository

git clone https://github.com/jenushreej1106/stylecart.git

### 2. Open the Project Folder

cd stylecart

### 3. Install PHP Dependencies

composer install

### 4. Configure Environment

Copy `.env.example` to `.env` and configure your database settings.

copy .env.example .env

Generate the application key:

php artisan key:generate

### 5. Create the Database

Create a MySQL database named `stylecart`.

Update the database configuration in your `.env` file.

### 6. Run Migrations


php artisan migrate


### 7. Create the Storage Link


php artisan storage:link

### 8. Start the Application


php artisan serve

Open the application at:

http://127.0.0.1:8000

## 🧪 Run Tests


php artisan test
